# 第80回麻布学園文化祭 デモサイト

第80回文化祭実行委員長選挙のためのデモです。**公式サイトではありません。** 掲載している内容は、
第79回文化祭のパンフレットなど、既に公開された情報を素材として使っています。

公開先: https://ruuuto.github.io/afes80/

## 何を見せるためのものか

既存の文化祭サイト（第77回、第79回）はいずれも Wix で作られています。ドラッグ配置の制約があるため、
要素は矩形のグリッドに並び、動きもフェードとスライドの既製品に限られます。このデモは、手で書けば
その制約の外に出られることを、3つの画面で示します。

| ページ | 中身 |
|---|---|
| `index.html` 展示と校舎 | 校舎の3Dモデル。階で絞り込み、部屋を押すと展示が出る。2つの展示を選ぶと階段やEVを含む最短経路が出る |
| `goods.html` 物販 | 第79回のグッズと価格 |
| `access.html` 行き方 | 最寄り駅と所要時間、広尾駅からの帰路の案内 |

見た目は白地に黒で、余白を広く取り、罫線を減らしています。書体はヒラギノ角ゴを先頭にした和文の並びと、
欧文および数字に SF Pro と Inter を当てています。部屋番号、価格、徒歩分数は、どのページでも同じ書体で
大きく出しています。この文化祭では展示を3桁の番号で呼ぶので、数字が共通の目印になります。

## 作り

ビルド工程はありません。`index.html` を開けば動きます。

| ファイル | 役割 |
|---|---|
| `index.html` `goods.html` `access.html` | 3ページ |
| `style.css` | 見た目。ページ間の切り替えの動きは `@view-transition` の1行だけ |
| `site.js` | 全ページ共通。ハンバーガーと、物販・行き方の描画 |
| `app.js` | 展示と校舎のページ。一覧、絞り込み、経路の表示 |
| `map3d.js` | 校舎の3Dモデル、経路のグラフ、ダイクストラ法 |
| `data/*.json` | 展示、グッズ、アクセスのデータ |
| `assets/*.png` | パンフレットから切り出した画像 |

使っている外部のものは three.js（CDN）と Google Fonts の2つだけです。フレームワークもビルドツールも
入れていません。

**更新したら `?v=` の番号を上げてください。** GitHub Pages は CSS と JS をブラウザに保存させるので、
新しいHTMLと古いJSが混ざって壊れます。番号は3つのHTMLの読み込み行と、`app.js` 冒頭の import にあります。

```bash
grep -rn '?v=' *.html app.js
```

ローカルで見るときは、`fetch` が `file://` では動かないので、簡易サーバーを立ててください。

```bash
python -m http.server 8731
```

## 3Dモデルについて

校舎は**模式図であって実測図ではありません。** パンフレットの平面図には寸法の記載がないため、
普通教室の一般的な大きさから置いた概算で組んでいます。寸法は `map3d.js` の `GEOM` にまとめてあるので、
実寸が分かればそこだけ直せば全体が追従します。

```js
export const GEOM = {
  CW: 7,     // 教室の間口
  CD: 9,     // 教室の奥行き
  COR: 2.6,  // 廊下の幅
  FH: 3.9,   // 階高
  GAP: 0.55, // 教室どうしの壁
  FLOORS: 4,
};
```

外観は学校公式サイトの写真を見て起こしました。中庭に面した規則的な窓の桟、車寄せとその上の塔屋、
塔屋の星章、屋上のパラペットを入れています。平面は単純な矩形ではなく、北へ張り出す部分と東の別棟が
付きます。塔屋の位置は中庭の写真から目分量で置いたもので、裏が取れていません。

部屋の位置は、平面図から読み取った `wing`（北辺、西辺、南辺、東辺、張り出し）と `indexInWing`
（その辺の中で何番目か）から決めています。普通教室棟は中庭を囲むロの字型で、全階が同じ輪郭を
共有するため、この2つで位置が決まります。

教室は既定では無彩色で、選んだ部屋と経路の両端だけ赤くなります。階段は四隅に格子、エレベーターは南東に
二重の枠として図示していて、どちらも経路のグラフと同じ座標から引いているので、経路の線とずれません。

展示を選ぶと、説明が3Dと階のタブの間に出ます。一覧の行から説明の位置まで形を保ったまま動くのは、
View Transition API の `view-transition-name` を一覧の行と説明に付け替えているだけで、動きの計算は
ブラウザに任せています。対応していないブラウザや、タブが裏にあって動きが中断された場合は、
説明がそのまま表示されます。

経路の出発と目的は、この説明の「ここから出発」「ここへ行く」で決めます。両方そろうと自動で計算します。

経路の計算は、廊下の輪をグラフにして、部屋をその輪にぶら下げ、階段とEVで階をつないでいます。
ロの字なので回り方が2通りあり、最短経路の計算に意味があります。階段とEVは別の重みを持たせていて、
「階段を使わない」を選ぶと階段の辺を外して計算し直します。

### フロンティア展示の扱い

パンフレットの平面図では、310から343の8部屋がまとめて「フロンティア展示」と書かれています。これは展示の
名前ではなく、小さな展示が集まる場所の呼び名です。実際の展示51件はパンフレットP8に別途載っているので、
一覧ではそちらを1件ずつ出し、部屋を選ぶと中の展示がまとめて出るようにしています。展示の総数は96件です。
